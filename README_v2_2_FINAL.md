```bash
pip install -r requirements_professional_v2_2_FINAL.txt
streamlit run app_professional_v2_2_FINAL.py
```

## بيانات الدخول الأولى

- Username: `admin`
- Password: `ChangeMe_2026!`

يجب تغيير كلمة المرور قبل الاستخدام الفعلي.

## أهم خصائص النسخة

- SQLite مع WAL وForeign Keys وفهارس.
- صلاحيات: مدير النظام / مسؤول الامتحانات / مراقب.
- تسجيل دخول المتدرب بواسطة PIN.
- بنك أسئلة قابل للاستيراد من `app.py` القديم دون تشغيله.
- تحليل آمن لـ `QUESTIONS_DB` ودعم الحلقات البرمجية البسيطة.
- إزالة التكرار بالبصمة الرقمية.
- حالة جودة لكل سؤال: مراجعة مطلوبة / معتمد / مرفوض.
- لا تدخل الأسئلة غير المعتمدة الامتحان عند تفعيل شرط الاعتماد في القالب.
- إضافة وتعديل واعتماد الأسئلة.
- مراجع علمية لكل سؤال.
- قوالب امتحان قابلة للتخصيص.
- توزيع مستويات الصعوبة.
- حد للمحاولات وإمكانية إعادة الاختبار.
- حفظ الإجابات مباشرة في SQLite.
- تسليم تلقائي عند انتهاء الوقت.
- نتائج وشهادات PDF عربية.
- مراجعة الإجابات حسب إعداد القالب.
- تصدير النتائج Excel وCSV.
- نسخ احتياطي SQLite باستخدام backup API.
- سجل تدقيق Audit Log.

## استيراد البنك القديم

من: **بنك الأسئلة → استيراد بنك الأسئلة القديم**

يمكن رفع ملف `app.py` القديم أو جلب النسخة من GitHub.

الاستيراد لا يشغّل التطبيق القديم؛ تتم قراءة بنية `QUESTIONS_DB` فقط.

## ملاحظة مهمة

الأسئلة المستوردة من النسخة القديمة تدخل افتراضيًا بحالة **مراجعة مطلوبة**. يجب مراجعتها واعتمادها قبل استخدامها في قالب يشترط الاعتماد العلمي.
